How to Use Bulk Actions

  1. Select Items: Use individual checkboxes or the "Select All" checkbox in the header
  2. Bulk Actions Appear: When items are selected, bulk action buttons will appear
  3. Choose Operation: Click on the desired bulk action (Delete, Export, Update, Revoke)
  4. Confirm Action: Review the selection and confirm the operation
  5. Monitor Progress: Watch for success/error messages and table updates
